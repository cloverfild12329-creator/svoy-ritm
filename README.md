# Свой ритм

Telegram Mini App для личных привычек и наград. Отдельный проект, не затрагивающий DiMoney.

## Что работает

- Привычки с расписанием по дням недели, категориями и цветами.
- Минуты, часы, литры, миллилитры, повторения, шаги, расстояние, страницы, свои единицы и простая отметка.
- Частичное выполнение, быстрые кнопки, исправление результата, архив.
- Баллы один раз за достижение дневной цели. Исправления отменяют начисление. Пропуски не штрафуются.
- Награды с ценами, подтверждением получения и историей списаний.
- Календарь и статистика по категориям.
- Светлая и тёмная темы, Telegram WebApp SDK, встроенный справочник.
- Сохранение на устройстве, экспорт и восстановление JSON с проверкой данных.

## Запуск

Нужен Node.js 20 или новее. Зависимостей нет.

```sh
npm ci
npm test
npm start
```

Открыть http://localhost:4173. Проверка сервиса: `/health`. Порт на Render берётся из переменной `PORT`.

## GitHub и Render

1. Создать отдельный репозиторий `svoy-ritm` и загрузить содержимое этой папки. Файл `package.json` должен быть в корне репозитория.
2. В Render создать Web Service, подключить этот репозиторий. Среда: Node. Build Command: `npm ci`. Start Command: `npm start`. Health Check: `/health`. Можно использовать включённый `render.yaml` через Blueprint.
3. Выбрать подходящий тариф самостоятельно. Конфигурация предлагает free; доступность и ограничения зависят от аккаунта Render.
4. После успешного запуска проверить `/health` и открыть основной адрес.
5. Для Telegram создать отдельного бота в официальном @BotFather, затем выбрать бота → Bot Settings → Menu Button → указать HTTPS-адрес Render и подпись «Свой ритм».
6. Открыть бота и нажать кнопку приложения. Токен бота для этой версии не нужен: она не вызывает Bot API и не отправляет личные записи на сервер.

## Границы первой версии

Данные сохраняются в localStorage на конкретном устройстве и в конкретном браузере. Это не облачная синхронизация. Очистка данных Telegram/браузера удалит локальные записи. Для переноса используется резервная копия в настройках. В Telegram экспорт файла зависит от клиента; при необходимости используйте браузер и храните данные в нём последовательно — это отдельное хранилище от Telegram.

Telegram user ID используется только для разделения локального хранилища, не для серверной авторизации. Сервер раздаёт только статические файлы, не принимает персональные данные и не предоставляет защищённых API. При добавлении облачного хранения потребуется серверная проверка Telegram initData и изоляция данных пользователей.

Автоматические напоминания и синхронизация пока не реализованы. Награды виртуальные: пользователь получает их самостоятельно. Изменение привычки действует сразу, пересчитывая сегодняшние баллы; смена единицы обнуляет сегодняшний результат. Удаление привычки снимает весь заработанный за неё опыт, сохраняя историю; архивирование также сохраняет текущий день. Возвращение из архива создаёт новую привычку, сохраняя прежнюю историю. Исправление уже потраченных баллов может сделать баланс отрицательным — новые выполнения его восстановят.

## Проверки

`npm test` проверяет частичный прогресс, однократные начисления, исправления после трат, расписание, архив, версии целей, дробные значения и повреждённые копии.
